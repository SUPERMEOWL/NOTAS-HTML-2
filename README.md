# Sistema de Apuntes - Método Cornell

Una aplicación web interactiva diseñada para tomar, organizar y gestionar apuntes de estudio utilizando el **Método Cornell**.


## Características

* **Estructura Cornell:** División limpia para título, palabras clave (*keywords*), desarrollo del tema y resumen.
* **Organización por Materias:** Menú para navegar entre diferentes asignaturas.
* **Integración con la Nube:** Conexión con Firebase para guardar los apuntes en tiempo real.


## Tecnologías utilizadas

* **HTML5** & **CSS3**
* **JavaScript** (Módulos ES6)
* **Firebase** (Firestore / Auth)


## Configuración e Instalación Local

Si querés probar este proyecto en tu equipo:

1. Cloná este repositorio.
2. En la carpeta `js/`, copiá el archivo `firebaseConfig.Example.js` y renombralo a `firebaseConfig.js`.
3. Reemplazá los valores de prueba con tus propias credenciales de Firebase.
4. Abrí el proyecto utilizando **Live Server** en VS Code.
